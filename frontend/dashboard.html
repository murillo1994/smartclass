Comportamento Térmico & Inércia

Salas de aula com alta densidade de alunos tendem a sofrer elevação gradual de temperatura. Acompanhar a curva de tendência permite antecipar o acionamento de climatizadores antes que o ambiente atinja a faixa de desconforto (> 24.5 °C).

Umidade Relativa e Saúde Respiratória

A Organização Mundial da Saúde (OMS) recomenda manter a umidade relativa entre 40% e 70%. Valores abaixo de 30% ressecam vias respiratórias e diminuem a barreira imunológica, enquanto valores acima de 80% favorecem fungos e ácaros.

Auditoria & Imutabilidade dos Registros

Todos os registros de telemetria são imutáveis (append-only) e possuem carimbos de data/hora gerados nativamente pelo PostgreSQL (CURRENT_TIMESTAMP), garantindo conformidade com a Constituição do SmartClass.

Arquitetura de Ponta a Ponta do SmartClass

Pipeline de telemetria dividido em três camadas desacopladas e resilientes

Ambiente de Demonstração (Modo Simulação Contínua)

O microcontrolador ESP32 físico encontra-se em fase de bancada. O sistema está executando com o Motor de Simulação Autônomo ativo, que transmite variações térmicas e de umidade realistas diretamente ao backend Flask e PostgreSQL, mantendo 100% de paridade com o hardware real.

1

Captura Física (ESP32)

O sensor DHT22 coleta temperatura e umidade a cada intervalo e monta o payload JSON.

Wi-Fi 2.4GHz • HTTP POST
2

Ingestão (API Flask)

Recebe POST /api/v1/medicoes, valida tipos e limites físicos.

Python 3.11 • RESTful
3

Persistência Imutável

Grava o registro com marcação temporal precisa do servidor (CURRENT_TIMESTAMP).

PostgreSQL 16 Relacional
4

Painel Web Reativo

Tailwind • Chart.js • jsPDF

Pinagem do Sensor no ESP32

Esquema elétrico de ligação com sensor DHT11 ou DHT22:

Pino Sensor Pino ESP32 Função
VCC (+) 3.3V / VIN Alimentação elétrica
DATA (Sinal) GPIO 4 Sinal digital de telemetria
GND (-) GND Terra comum

Contrato de Ingestão JSON

Payload transmitido via POST /api/v1/medicoes:

{
  "sala_id": "Sala 101",
  "temperatura": 23.50,
  "umidade": 58.20
}

* O campo umidade é opcional para sensores legados de temperatura única.
